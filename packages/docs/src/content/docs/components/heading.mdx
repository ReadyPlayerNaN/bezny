Semantic heading components with automatic heading level management via context.

```tsx
import { Heading, StaticHeading, HeadingLevelProvider, useHeadingLevel } from "@bezny/text";
```

## Examples

### Heading with Context

When nested inside `HeadingLevelProvider`, headings automatically increment their level.

<LivePreview client:load code={`<HeadingLevelProvider>
  <Heading>Top Level (h1)</Heading>
  <HeadingLevelProvider>
    <Heading>Nested (h2)</Heading>
    <HeadingLevelProvider>
      <Heading>Deeper (h3)</Heading>
    </HeadingLevelProvider>
  </HeadingLevelProvider>
</HeadingLevelProvider>`} />

### Explicit Levels

<LivePreview client:load code={`<div>
  <Heading level={1}>Heading 1</Heading>
  <Heading level={2}>Heading 2</Heading>

### StaticHeading

`StaticHeading` always renders at the specified level, ignoring context.

<LivePreview client:load code={`<div>
  <StaticHeading level={2}>Always h2</StaticHeading>
  <StaticHeading level={4}>Always h4</StaticHeading>
</div>`} />

## API Reference

### Heading

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | Context + 1 | Explicit heading level. If omitted, derived from context. |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
| `children` | `ReactNode` | — | Heading content |
| `...rest` | `ComponentPropsWithoutRef<"h1">` | — | All other native heading attributes |

### StaticHeading

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | **required** | The heading level to render |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
| `children` | `ReactNode` | — | Heading content |
| `...rest` | `ComponentPropsWithoutRef<"h1">` | — | All other native heading attributes |

### HeadingLevelProvider

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `level` | `0 \| 1 \| 2 \| 3 \| 4 \| 5` | Current + 1 | Explicit context level. If omitted, increments from parent. |
| `children` | `ReactNode` | — | Child components |

### useHeadingLevel

A hook that returns the current heading level from `HeadingLevelContext`.

Returns `HeadingLevel` (`0 | 1 | 2 | 3 | 4 | 5`).

```tsx
import { useHeadingLevel } from "@bezny/text";

function MyComponent() {
  const level = useHeadingLevel();
  return <span>Current heading level: {level}</span>;
}
```
