A select input with label support and validation.

```tsx
import { SelectInput } from "@bezny/input";
```

## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassValue` | — | Additional CSS classes |
| `defaultValue` | `string` | — | Initial value (uncontrolled) |
| `disabled` | `boolean` | — | Disables the select |
| `label` | `string` | — | Label text |
| `name` | `string` | — | HTML name attribute |
| `onChange` | `(value: string) => void` | — | Called with the selected value |
| `options` | `SelectInputOption[]` | — | Array of `{ label, value }` objects |
| `placeholder` | `string` | — | Placeholder option text |
| `status` | `"error" \| "warning" \| "success"` | — | Validation status |
| `statusMessage` | `string` | — | Validation message |
| `value` | `string` | — | Controlled value |
