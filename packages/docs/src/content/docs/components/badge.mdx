## API Reference

### Badge

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "success" \| "warning" \| "danger" \| "info" \| "primary" \| "secondary"` | `"default"` | Visual style variant |
| `size` | `"sm" \| "md"` | `"md"` | Size of the badge |
| `dot` | `boolean` | `false` | Show a colored dot indicator before the label |
| `className` | `ClassValue` | — | Additional CSS classes |
| `children` | `ReactNode` | — | Badge content |
