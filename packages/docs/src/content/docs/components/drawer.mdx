A slide-in panel with overlay backdrop, focus trapping, and Escape key support.

```tsx
import { Drawer } from "@bezny/drawer";
```

## Examples

### Drawer Sides

<LivePreview client:load noInline code={`function DrawerDemo() {
  const [open, setOpen] = React.useState(false);
  const [side, setSide] = React.useState("right");
  const openSide = (s) => { setSide(s); setOpen(true); };
  return (
    <div style={{ display: "flex", gap: "8px", flexWrap: "wrap" }}>
      <Button onClick={() => openSide("left")}>Left</Button>
      <Button onClick={() => openSide("right")}>Right</Button>
      <Button onClick={() => openSide("top")}>Top</Button>
      <Button onClick={() => openSide("bottom")}>Bottom</Button>
      <Drawer open={open} onClose={() => setOpen(false)} side={side}>
        <Heading>Drawer Content</Heading>
        <Paragraph>This drawer slides in from the {side}.</Paragraph>
      </Drawer>
    </div>
  );
}
render(<DrawerDemo />);`} />

## API Reference

### Drawer

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | **required** | Controls drawer visibility |
| `onClose` | `() => void` | **required** | Called on Escape press or outside click |
| `side` | `"left" \| "right" \| "top" \| "bottom"` | `"right"` | Which side the drawer slides from |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
| `children` | `ReactNode` | — | Drawer content |
