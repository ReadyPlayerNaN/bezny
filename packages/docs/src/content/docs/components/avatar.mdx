Displays user avatars with initials fallback and Gravatar support.

```tsx
import { Avatar } from "@bezny/avatar";
```

## Examples

### Sizes

The Avatar component supports three sizes: `sm`, `md`, and `lg`.

<LivePreview client:load code={`<div style={{ display: "flex", gap: "12px", alignItems: "center" }}>
  <Avatar name="Alice Smith" email="alice@example.com" size="sm" />
  <Avatar name="Bob Jones" email="bob@example.com" size="md" />
  <Avatar name="Carol White" email="carol@example.com" size="lg" />
</div>`} />

## API Reference

### Avatar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string` | **required** | User's display name (used for alt text and initials fallback) |
| `email` | `string` | **required** | User's email (used for Gravatar lookup) |
| `avatarUrl` | `string \| null` | `null` | Custom avatar image URL |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Avatar size (24px, 40px, 64px) |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
