Renders markdown strings as styled HTML using bezny components.

```tsx
import { Markdown } from "@bezny/markdown";
```

## Examples

### Interactive Demo

<MarkdownDemo client:load />

### Basic Usage

```tsx
<Markdown content="## Hello\n\nSome **bold** text and a [link](https://example.com)." />
```

## API Reference

### Markdown

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `string` | — | Markdown source to render |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
