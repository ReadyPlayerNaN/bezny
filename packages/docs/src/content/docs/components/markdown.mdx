---
title: Markdown
---

Renders markdown strings as styled HTML using bezny components.

```tsx
import { Markdown } from "@bezny/markdown";
```

## Examples

### Basic Markdown

```tsx
<Markdown content="## Hello\n\nSome **bold** text and a [link](https://example.com).\n\n- Item one\n- Item two" />
```

### Code in Markdown

```tsx
<Markdown content="Inline `code` and a block:\n\n```js\nconst x = 1;\n```" />
```

## API Reference

### Markdown

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `string` | — | Markdown source to render |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
