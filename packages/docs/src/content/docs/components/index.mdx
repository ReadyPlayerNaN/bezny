A gallery of all bezny components.

- [Alert](/components/alert/) — Semantic alert messages for success, warning, and error states

- [AvatarStack](/components/avatar-stack/) — Overlapping avatar stack with overflow count
- [Breadcrumbs](/components/breadcrumbs/) — Breadcrumb navigation with automatic current-page marking
- [Button](/components/button/) — Styled buttons with variant support
- [Card](/components/card/) — Compound card with header, body, footer, and image sections
- [Container](/components/container/) — Width-constraining wrapper with size presets
- [Dialog](/components/dialog/) — Modal dialogs built on the native dialog element
- [Drawer](/components/drawer/) — Slide-in panel with overlay backdrop and focus trapping
- [Dropdown](/components/dropdown/) — Positioned dropdown anchored to a trigger element
- [Heading](/components/heading/) — Headings with automatic level management via context
- [Label](/components/label/) — Styled label for form elements
- [Navbar](/components/navbar/) — Responsive navigation bar with collapsible sections
- [Overlay](/components/overlay/) — Backdrop overlay rendered via portal
- [Paragraph](/components/paragraph/) — Styled paragraph component
- [Semantic Elements](/components/semantic-elements/) — Article, Section, Aside, Main wrappers
- [Stack](/components/stack/) — Flex-based layout for arranging children with spacing
