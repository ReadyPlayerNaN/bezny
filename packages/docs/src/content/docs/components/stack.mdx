A flex-based layout component for arranging children vertically or horizontally with consistent spacing.

```tsx
import { Stack } from "@bezny/layout";
```

## Examples

### Vertical Stack

<LivePreview client:load code={`<Stack gap={2}>

</Stack>`} />

## API Reference

### Stack

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `direction` | `"vertical" \| "horizontal"` | `"vertical"` | Layout direction |
| `gap` | `number` | — | Gap between items in 4px units (e.g. `gap={2}` = 8px) |
| `className` | `ClassValue` | — | Additional CSS classes (clsx-compatible) |
| `children` | `ReactNode` | — | Stack content |
